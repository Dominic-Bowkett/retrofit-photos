Rooms

Add a room for each space you photograph, then tag each photo (Room, Undercuts, Windows, Lighting, Heating, Secondary Heating, Ventilation, Renewables, Meters, Other).

How it works

  • Tap Enable GPS once so each photo can be stamped with its coordinates.
  • Inside each group, tap Take photo to capture a shot with the device camera — the date/time recorded is the moment the photo is taken.
  • Every image is re-rendered with a date/time and GPS overlay in the bottom right corner.
  • Work is autosaved to this browser — refresh or close the tab and it's still here. Switch between multiple properties using the picker above.

By group lists photos under External Elevations, Loft, each room, etc. — the same order as the app. By Tag shows tagged photos first, grouped by their tag (Room, Meters, Windows, etc.), then any untagged photos in an "Untagged" section at the end. Settings

Configure the Claude API key used to analyse photos (identify meter make/model, smart-meter status, boiler specs, etc.).

Key is stored in this browser only — in localStorage, which any code running on this page (including browser extensions) can read. Create a dedicated API key with spend limits on the Anthropic Console and rotate it if you suspect it's been exposed. The key never leaves your device except when making a request to api.anthropic.com.

Auto-label & tag

Generate labels or photo tags (Heating / Meters / Windows / …) across this property using Claude.

Every newly-captured photo starts with a default label like "Bedroom 1 — 3". Run auto-label replaces those with something more descriptive while leaving any labels you've typed manually alone. Run auto-tag sorts photos into the same tags the camera-capture flow uses (Heating / Meters / Ventilation / …). Uses the model chosen in Settings — Haiku is much cheaper for bulk runs.

    Export photos

    Choose how to export the photos from this property. Date and GPS metadata are preserved in both options — stamped camera captures and uploaded photos both retain their EXIF data.

    Save to Photos opens your device's share sheet — tap Save Image (iOS) or Save to Gallery (Android) to copy the batch to your camera roll. Download ZIP (compressed) is the safe default — photos are re-encoded a little smaller so very large jobs still fit within iOS in-app memory. Download ZIP (originals) keeps every photo at capture quality. Very large jobs are split automatically into parts so each archive stays inside iOS in-app memory. Tick Share each ZIP via system to send the archives straight to Drive, Files, or any installed app via the OS share sheet (recommended on iPhone PWA — much more reliable than direct downloads). The ↓ button on any thumbnail always saves a single photo at full fidelity.
